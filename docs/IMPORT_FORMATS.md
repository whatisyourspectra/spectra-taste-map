# 곡 목록 가져오기

지원 형식: TuneMyMusic CSV/TXT, 쉼표·세미콜론·탭 구분 표, UTF-8/BOM·UTF-16 텍스트, tracks/items/playlists 배열을 가진 JSON 목록. 파일 크기는 최대 10MB, 가져오는 곡 수는 기존 MAX_IMPORT_TRACKS 한도를 따릅니다. 바이너리 엑셀·이미지·오디오 또는 곡명/아티스트가 없는 데이터는 곡 목록으로 변환할 수 없습니다.

- CSV 헤더 순서에 관계없이 곡명·아티스트 열을 찾습니다. 따옴표 안의 쉼표·줄바꿈·이스케이프를 처리합니다.
- TXT는 Artist - Title, 탭 구분을 지원합니다.
- 중복 수와 읽지 못한 행 수를 표시합니다. 잘못된 JSON이나 누락된 열은 사용자에게 알립니다.
- 원본 곡 목록을 즉시 보존하고 지도를 연 뒤, 5곡씩 최대 2개 요청으로 분석합니다.
- 분석 전 좌표 값은 중립값이며 음악 분석 결과가 아닙니다. 장르를 임의 생성하지 않습니다. 서버가 실패해도 곡명·아티스트·앨범을 유지하고 분석 대기/재시도를 표시합니다.
- 분석 결과는 원본 importKey로 교체해 보정된 곡명이 중복되지 않도록 합니다.
- 외부 분석은 요청별 기한을 두고, 첫 묶음이 전부 실패하면 전체 목록에 같은 실패를 반복 호출하지 않습니다.

검증: tests/importTracks.test.mjs. 실제 hw.csv/hw.txt는 최초 조사에서 각각 201곡으로 확인했고, 201곡 CSV/TXT 검증 파일로 브라우저의 API 성공·503 실패 경로를 검증했습니다.
