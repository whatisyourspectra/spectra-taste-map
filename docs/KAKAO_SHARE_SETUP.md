# 카카오톡 취향 카드 공유 설정

1. 카카오 개발자 콘솔 → 앱 → 플랫폼 키 → JavaScript 키를 복사합니다.
2. 로컬 `.env`와 Vercel 환경 변수에 `VITE_KAKAO_JAVASCRIPT_KEY`로 등록합니다. REST API 키나 Client Secret을 넣지 않습니다.
3. JavaScript 키의 SDK 도메인에 실제 사용하는 사이트 origin을 등록합니다. 예: `https://spectra-music.org`, `https://www.spectra-music.org`, 개발용 `http://localhost:5173`.
4. 앱 → 제품 링크의 Web 도메인에도 실제 공유 링크의 사이트 도메인을 등록합니다.
5. 환경 변수 변경 후 개발 서버 재시작 또는 재배포합니다.
6. 모바일 공유 카드에서 별자리/앨범 버블 선택 → 카카오톡 공유 준비 → 카카오톡 열기 → 대화방 선택을 검증합니다.

기본 Feed 템플릿을 사용하므로 사용자 정의 템플릿 ID는 필요하지 않습니다. 카드 준비를 누를 때만 이미지를 카카오 서버에 업로드하고, 전송은 사용자가 대화방을 선택해 완료합니다. `/share/card` 링크로 로그인 없이 이미지가 열립니다. 개인 지도 전체나 계정 ID는 링크에 포함하지 않습니다.

카카오에 업로드한 이미지는 최대 100일 보관됩니다. 영구 공개 지도 링크가 아닌 이미지 카드 공유입니다.

공식 문서: https://developers.kakao.com/docs/ko/kakaotalk-share/js-link

## 친구가 탐색하는 공유 지도

Supabase SQL Editor에서 `docs/shared_taste_maps.sql`을 한 번 실행합니다. 나의 스펙트라 공유 카드에서 **카카오톡 공유 준비**를 누르면 로그인한 사용자가 원본과 분리된 지도 사본을 저장합니다. UUID 링크를 받은 누구나 조회할 수 있고, 원본을 수정하지 않습니다. 현재 카드 창의 **지도 공유 해제**로 사본을 삭제할 수 있습니다. 원본 지도 변경은 기존 공유 사본에 자동 반영되지 않습니다.

## 메시지에 지도 버튼이 없는 경우

배포 빌드는 공유 링크를 `https://www.spectra-music.org`로 통일합니다. 카카오 콘솔의 **앱 → 제품 링크 관리 → 웹 도메인**에 `https://www.spectra-music.org`와 `https://spectra-music.org`를 등록하세요. SDK 도메인 등록(이미지 업로드 허용)과 제품 링크 도메인 등록(메시지 링크 허용)은 별도입니다. 이미 전송한 메시지는 바뀌지 않으므로 설정 후 새 카드를 전송합니다. 공유 준비 완료 화면의 **지도 직접 보기**로 링크를 확인하고 **지도 링크 복사**로 주소를 별도로 보낼 수 있습니다.

지도 카드에는 체크박스 없이 공유 지도 링크가 자동 포함됩니다. 지도 저장 실패 시 이미지 전용 공유로 조용히 전환하지 않고 오류를 표시합니다. Daily 카드처럼 곡 목록이 없는 카드는 이미지 카드 보기 링크가 포함됩니다.
