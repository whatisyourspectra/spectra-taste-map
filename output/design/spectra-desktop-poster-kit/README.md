## 따로 꺼내 쓰는 UI SVG 20종

`ui-svg/`에 같은 이름의 SVG와 PNG가 들어 있습니다. PNG의 긴 변은 약 4,000px입니다.

- **서비스 구성:** 헤더, 지도 도구 모음, 영역 필터, 확대·축소, 발견·곡 선택 버튼
- **지도:** 앨범 지도, 단독 지도, 별자리 지도
- **곡 상세:** 곡·별자리 카드, 듣기·항해 버튼, 별자리 프리뷰, 분류 근거
- **별자리 항해:** 상단바, 재생 컨트롤, 재생목록
- **음악 정리:** 선택한 곡으로 이름 붙이는 그룹 편집 패널
- **새 음악 찾기:** 추천 패널, 추천곡 행, 목록 상태·개수
- **홈:** 랜딩 내비게이션

SVG는 브라우저 DOM에서 위치·치수·문구·색을 추출해 **네이티브 벡터 도형·경로로 재구성**했습니다. 글자는 윤곽선입니다. Illustrator/Figma에서 그룹을 풀어 위치·크기·색을 수정할 수 있으며 폰트를 설치하지 않아도 보입니다. 글자 내용을 바꿀 때는 새로 입력하거나 생성 소스를 수정하세요.

앨범 커버와 캔버스 효과 레이어는 이미지로 포함되어 있습니다. 전체를 단일 스크린샷으로 넣은 UI SVG나 `foreignObject` 방식은 사용하지 않았습니다. 브라우저의 블러·그림자·복합 배경 효과와 일부 기호는 SVG 호환성을 위해 단순화했습니다. 원본과 비교하려면 `sources/*-reference.png`를 확인하세요.

## 실제 화면과 데모 데이터

- 현재 로컬 SPECTRA 웹 애플리케이션을 **1,600 × 1,000 데스크톱 뷰포트**, 기기 배율 3으로 촬영했습니다. 실제 화면 원본 9종은 각각 **4,800 × 3,000px**입니다.
- `getCombinedDemoTracks()`에 있는 고유 곡 69개를 사용했습니다. 원본 커버가 있는 18곡과 기본 생성 커버 51곡을 모두 포함했습니다.
- 생성 커버는 원래 SVG 그림을 그대로 Base64 URI로 인코딩해 CSS 배경에서 회색으로 누락되지 않게 했습니다. 곡·아트워크의 내용과 수를 바꾸지 않았습니다.
- 전체 화면, 지도, 곡 상세, 항해, 그룹 시연에는 69곡을 사용했습니다. 보여 주는 영역과 카메라는 실제 서비스의 지도 보기·전체 보기·곡 선택 동작으로 조정했습니다.
- **새 음악 찾기 컷은 기존 69곡 중 61곡을 라이브러리로 두고 나머지 8곡을 추천 API의 시연 응답으로 사용했습니다.** 새 곡을 지어내거나 이미 있는 곡을 중복 추천하지 않았습니다. 실시간 추천 품질을 보여주는 결과는 아닙니다.
- 곡 그룹은 실제 데모 곡 3개를 선택한 상태입니다. 그룹 이름 `Night Drive`는 시연용 입력입니다.
- 별자리 항해의 YouTube 플레이어는 외부 오디오 없이 정지/큐 상태로 표시했습니다. 스트리밍 재생을 검증한 영상은 아닙니다.
- 로그인·실제 계정 저장·메시지 전송은 하지 않았습니다. 제품 소스 UI·CSS를 변경하지 않았습니다.

캡처 조건은 `capture-audit.json`, 출력 크기는 `vector-manifest.json`과 `macbook-manifest.json`에 있습니다.

## 포스터에 배치하는 순서

1. 서비스 소개에는 **01 맥북 전체 화면**을 사용합니다.
2. 맵 설명에는 **04 지도와 곡 상세** 또는 **07 단독 지도**를 사용합니다.
3. 기능 설명에는 **05 기능 모아보기**를 쓰거나 `ui-svg/`에서 필요한 패널을 직접 조합합니다.
4. 별자리 항해를 강조하려면 **06 항해 화면**과 **15-voyage-queue.svg**를 함께 배치합니다.

PNG는 RGB입니다. 최종 포스터에서 인쇄 업체의 프로파일과 도련을 적용하세요. 이미지 레이어의 선명도는 포함된 원본 이미지의 해상도에 영향을 받습니다.

## 제작 소스

- `capture-desktop.mjs`: 실제 서비스 동작을 통한 화면·DOM 모듈 캡처
- `dom-snapshot.js`: 네이티브 SVG를 만들기 위한 DOM 기하·스타일 추출
- `build-vectors.mjs`: 글자 윤곽선, 벡터 UI와 히어로 조합 생성
- `macbook.html`, `macbook.js`, `render-macbook.mjs`: Three.js/WebGL 맥북 목업
- `build-gallery.mjs`: 오프라인 갤러리와 모아보기 생성

소스는 현재 SPECTRA 저장소 및 로컬 Chrome·Playwright·resvg 경로를 사용합니다. 완성 SVG·PNG·갤러리는 생성 도구 없이 열 수 있습니다. 생성형 이미지 API는 사용하지 않았습니다.

UI 서체는 프로젝트의 Space Grotesk / Syne를 사용했습니다. Space Grotesk는 [제작자의 공식 저장소](https://github.com/floriankarsten/space-grotesk/tree/master/fonts/ttf)에서 받았고 라이선스를 `sources/fonts/OFL.txt`에 포함했습니다. 한글 일부의 윤곽선에는 로컬 KoPubWorld Dotum을 사용했습니다.
