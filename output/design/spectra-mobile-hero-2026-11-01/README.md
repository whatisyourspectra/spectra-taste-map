## 화면의 출처

- 현재 로컬 SPECTRA React 애플리케이션의 `/taste-map?lang=en`을 모바일 뷰포트 393 × 852, 기기 배율 4로 실행했습니다.
- 원본 화면 PNG는 1,572 × 3,408 px이며 `sources/`에 들어 있습니다.
- 화면에는 저장소에 있는 실제 데모 곡 18개를 사용했습니다. 원본 앨범 커버를 불러오는 곡만 선택했습니다. 개인 계정이나 개인 음악 데이터를 사용하지 않았습니다.
- 앞 기기: 실제 **Constellation** 보기. 뒤 기기: 실제 **Space Song / Beach House** 곡 선택 화면.
- 현재 제품의 버튼, 글꼴, 간격, 지도 표시와 카카오톡 공유 버튼은 수정하지 않았습니다. 별도의 UI 디자인을 그려 넣지 않았습니다.
- 폰 프레임, OS 상태 표시줄과 홈 인디케이터는 포스터용 목업 그래픽입니다. 네이티브 앱 출시를 뜻하지 않습니다.
- `sources/capture-audit.json`에 사용한 곡과 캡처 조건이 기록되어 있습니다.

## SVG 사용

01–04 SVG의 기기 프레임과 장식·글자는 벡터입니다. **화면은 실제 캡처 PNG를 파일 안에 포함**했습니다. SVG 전체가 순수 벡터인 것은 아닙니다. 외부 이미지 연결이나 폰트 설치 없이 사용할 수 있습니다.

프레임 확대와 배치 수정은 SVG에서 할 수 있습니다. 화면의 선명도는 원본 캡처 해상도의 영향을 받습니다. PNG는 RGB이며 01·03·04에는 투명도가 있습니다. 인쇄 색상과 도련은 최종 포스터에서 맞추세요.

## 스튜디오 렌더

05는 실제 캡처 두 장을 입력해 내장 `image_gen` 도구로 생성한 별도 목업입니다. 원본 레퍼런스는 앨범 버블 보기와 곡 선택 보기입니다. 생성형 렌더이므로 일부 화면 글자·아이콘·배치와 기기 가장자리가 원본과 다를 수 있습니다. **현재 제품 화면을 정확히 보여주고 대형 인쇄할 때는 01–04를 사용하세요.**

전체 제작 프롬프트는 `sources/studio-render-prompt.txt`에 저장했습니다. 05는 원본 해상도로 제공하며 저해상도 결과를 6,000px로 확대하지 않았습니다.

## 재생성

- `capture.mjs`: 로컬 Vite + Chrome에서 실제 UI 캡처. 로컬 데모만 사용하며 로그인·계정 저장·추천 API 요청을 하지 않습니다.
- `render.mjs`: 실제 UI 원본을 포함한 SVG 목업과 고해상도 PNG 생성.
- 두 스크립트는 현재 저장소와 로컬 도구 경로를 사용합니다. 완성된 PNG·SVG는 별도 도구 없이 열 수 있습니다.
