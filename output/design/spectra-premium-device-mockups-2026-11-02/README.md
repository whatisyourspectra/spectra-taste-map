# SPECTRA 프리미엄 데스크톱 목업

사용자 데스크탑 원본 `스크린샷 2026-11-01 오후 10.38.29 1.png`를 사용했습니다. 원본은 6221×4040px이며 `sources/`에 복사해 보존했습니다.

## 파일 선택

- `01-macbook-studio-ai.png`: 1536×1024px, 생성형 스튜디오 맥북 목업. 금속 질감과 조명 중심의 시안입니다.
- `02-imac-studio-ai.png`: 1536×1024px, 생성형 스튜디오 아이맥 목업.
- `03-macbook-front-8k.png`: 7680×5760px, 원본 스크린샷을 화면 텍스처로 넣은 정면 맥북 스타일 3D 목업.
- `04-macbook-angle-8k.png`: 7680×5760px, 같은 화면의 사선 맥북 스타일 3D 목업.
- `05-imac-angle-8k.png`: 7680×5760px, 같은 화면의 아이맥 스타일 3D 목업.

모든 PNG에 알파 채널이 있습니다. 생성형 버전에는 기기 바깥의 반투명 조명 번짐도 포함되어 있습니다. 8K 버전은 기기 바깥이 완전히 투명합니다.

## 제작 방식과 사용 범위

생성형 2종은 내장 `image_gen.imagegen`으로 제작했으며 실제 출력 크기 그대로 보관했습니다. 업스케일하지 않았습니다. 작은 한글, 곡 커버와 UI 세부 내용은 원본과 차이가 있어 화면 정확도가 필요한 인쇄에는 03–05를 사용하세요. 전체 프롬프트는 `prompts.json`에 있습니다.

8K 3종은 기존 프로젝트의 Three.js 목업을 확장해 새로 렌더링했습니다. 원본 스크린샷의 배치·글자를 재작성하지 않고 전체를 텍스처로 표시했습니다. 화면 비율을 맞추기 위한 검정 여백이 좌우에 조금 들어갑니다. 사용자 원본의 커서와 상단 검정 여백도 유지했습니다. 기기 외형은 자체 제작한 단순화된 모델이며 Apple 공식 모델/정확한 제품 CAD는 아닙니다.

8K 파일은 네 개의 3840×2880 네이티브 WebGL 타일을 합친 7680×5760 렌더입니다. 저해상도 이미지를 늘린 파일이 아닙니다. 다만 화면 콘텐츠 자체의 디테일은 원본 스크린샷 해상도가 한도입니다.

`START-HERE.html`에서 검정/밝은 배경에 맞춰 비교하고 PNG를 개별 다운로드할 수 있습니다. 포스터에는 03의 정면 구도가 화면을 크게 보여주기 좋습니다.
