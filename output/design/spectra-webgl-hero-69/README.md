## 데이터와 화면

저장소의 `getCombinedDemoTracks()`가 제공하는 **69개의 서로 다른 곡**을 모두 사용했습니다. 아티스트 표기는 20종이며, 커버는 기본 데모 구성인 원본 커버 18개와 생성 커버 51개에서 시작했습니다. 곡을 복제하거나 가상의 음악·추천·이용 통계를 추가하지 않았습니다.

현재 로컬 애플리케이션의 `/taste-map?lang=en`을 **430 × 932 모바일 뷰포트, 기기 배율 4**로 촬영했습니다. 제품 UI·CSS·장르 필터·지도 배치는 수정하지 않았습니다. 화면의 `69 tracks`는 실제 사용한 고유 곡 수입니다.

- 앞 폰: 전체 지도, 별자리 보기. 실제 화면에 표시된 별 **31개**.
- 뒤 폰: Space Song / Beach House를 선택한 별자리 지도. 실제 화면에 표시된 별 **25개**.
- 별 표시 개수는 제품의 충돌 방지와 화면 크기 제한에 따른 결과입니다. 69곡 전부를 한 화면에 억지로 표시하지 않았습니다.
- 추가 캡처: 실제 취향 둘러보기 화면을 키보드로 확대해 촬영했습니다.
- 실제 계정에 로그인하거나 클라우드에 저장하지 않았습니다. 화면의 곡·장르 정보는 기존 데모 데이터입니다.

`capture-render-audit.json`에 사용한 69곡의 ID·곡명·아티스트, 표시 개수와 렌더 조건이 들어 있습니다.

## 웹 렌더링

Three.js / WebGL로 폰의 두께, 모서리, 금속 프레임, 버튼, 카메라와 조명을 실제 3D로 구성했습니다. 곡 화면은 원본 캡처를 텍스처로 넣었습니다. 생성형 이미지 API는 사용하지 않았습니다.

환경 반사, 스튜디오 조명, 핑크·시안 보조광과 원근 카메라를 사용했습니다. 캔버스를 6,000 × 4,500 px로 직접 렌더링해 PNG로 내보냈습니다. 저해상도 이미지를 확대하지 않았습니다. UI 텍스처는 원본 캡처 해상도의 영향을 받습니다.

장식 궤도와 별은 포스터용 그래픽이며 새 제품 기능이나 추가 곡을 의미하지 않습니다. OS 상태 표시줄·홈 인디케이터는 기기 목업 요소입니다. PNG는 RGB이며, 최종 인쇄에서는 포스터 파일의 색상 프로파일과 도련 규격을 적용하세요.

## 다시 열거나 재생성하기

이 폴더는 현재 SPECTRA 저장소의 개발 서버에서 실행하는 렌더 소스입니다. `studio.html`을 파일로 직접 열면 `/node_modules/` 경로를 불러올 수 없으므로 서버를 통해 열어야 합니다.

저장소에서 `npm run dev:web` 실행 후 다음 경로로 접속하면 마우스 위치에 따라 기기 각도가 미세하게 움직이는 스튜디오를 확인할 수 있습니다.

`http://127.0.0.1:5173/output/design/spectra-webgl-hero-69/studio.html`

URL 끝에 `?alpha`를 붙이면 투명 배경 모드입니다. PNG 결과물은 서버 없이 바로 사용할 수 있습니다.

`render-web.mjs`는 실제 앱 캡처부터 WebGL 내보내기까지 실행하는 소스입니다. `--reuse-screens`를 붙이면 기존 캡처를 유지하고 조명·각도만 다시 렌더링합니다. 현재 작업 환경의 Chrome·Playwright 경로를 사용합니다.
