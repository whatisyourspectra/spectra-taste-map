# SPECTRA Drive

운전 중 손으로 고치기 어려운 음악 리스트를, 기존 SPECTRA 취향 데이터와 음성 무드 요청으로 재구성하는 차량용 앱 프로젝트.

현재 단계는 **음악·조명·이동 맥락을 연결한 브라우저 시제품**이다. 로컬 음원 파일은 실제로 재생한다. 차량 조명·내비게이션·위치 이벤트는 시뮬레이션이며 Gleo AI, Pleos SDK, Kotlin 앱, APK는 아직 구현하지 않았다. 운전자·Pleos 데모는 기존 SPECTRA의 곡 정보와 앨범 커버를 재사용하며 오디오 파일은 포함하지 않는다. 취향 수치는 데모용 예시값이다.

## 실행

```sh
cd spectra-drive
npm install
npm run dev
```

**운전자 시점 데모: http://127.0.0.1:5190/drive**. 기존 기능 시제품은 `/`, 이전 화면 시안은 `/design`이다. 이 저장소의 상위 프로젝트에 이미 의존성이 설치되어 있다면 현재 폴더에서 `npm run dev`로 바로 실행할 수 있다. 새 운전자 데모가 상위 `src/taste` 분석 함수를 직접 사용하므로, 개발할 때는 저장소 전체를 유지한다. 빌드한 `dist/`는 정적 파일로 배포할 수 있다.

```sh
npm test
npm run build
```

## 차량용 화면 시안

`/pleos`에서 **공식 Pleos Connect-S 17인치 배치 도안**을 적용한 웹 시안을 볼 수 있다. 시스템 영역을 유지하면서 SPECTRA 단독 또는 내비 예시 + SPECTRA 1:1 분할을 전환한다. 기존 한강 운전석과도 같은 상태로 전환하며 현재 음악은 계속 재생된다. [공식 템플릿 적용과 출처](docs/design/pleos-connect/README.md)에 Figma 다운로드 링크, 실제 사용한 벡터 도안, 캡처 및 모의 동작 범위를 기록했다. Pleos OS를 실행하는 앱이나 실제 아이오닉 6의 탑재 화면은 아니다.

`/drive`는 아이오닉 6의 듀얼 디스플레이 실내 구성을 참고한 운전자 시점의 인터랙티브 렌더링이다. 한강 노을과 실내 소재를 표현한 AI 생성 배경 위에 실제 앱 화면을 합성한다. 풍경은 정적인 콘셉트이며, 클러스터는 모의 화면이다. 실제 차량 탑재를 의미하지 않는다. **조명이 아니라 취향 기반 음악 대기열 변경이 핵심 경험**이다.

1. `28초 자동 시연` 또는 3개 예시 요청으로 대기열 변경을 확인한다.
2. 현재 곡과 취향 별자리의 위치는 유지되고 다음 곡만 재선정된다. `기본 취향으로`는 원래 분석 기준으로 복원한다.
3. `화면 확대`로 인포테인먼트를 크게 검토하고 `운전자 시점`으로 돌아온다. `몰입 보기`는 장면을 전체 화면으로 표시한다.
4. `직접 말하기` 또는 스티어링 휠의 마이크 버튼은 브라우저 음성 인식을 사용한다. 예시 버튼과 자동 시연은 명시적으로 모의 입력이다.
5. `내 데이터로 시연하기`에서 개인 JSON과 일치하는 로컬 음원을 연결하면 실제 재생을 확인할 수 있다. 무드 변경은 현재 곡의 재생을 끊지 않는다. 기본 데모에는 기존 SPECTRA의 곡·앨범 정보와 커버가 있으며 음원은 없다.

**앨범 커버:** `src/spectraDemoLibrary.js`가 기존 `src/taste/demoUniverses.js`의 세 장르 묶음에서 6곡씩 18곡을 재사용한다. 앨범 커버 17종은 원본 `public/demo-covers`의 파일을 그대로 복사하며, `predev`·`prebuild`에서 동기화한다. Pleos 단독 화면의 현재 곡 카드, 대기열, 하단 플레이어와 분할·한강 보기에서 같은 곡에 같은 커버를 표시한다. 개인 JSON의 `album`, `coverUrl`, `albumArt`, `imageUrl`, `album.images[0].url`도 인식한다. 없는 커버나 로딩에 실패한 이미지는 원본 SPECTRA의 SVG 레코드 아트로 대체한다. 커버를 찾기 위해 iTunes 등 외부 API를 호출하지 않는다. `내 데이터로 시연하기`에서 같은 더미 JSON을 내려받을 수 있다.

분석은 기존 `src/taste/buildTasteState.js`의 장르 분포와 평균값을 직접 사용한다. 대기열 순위는 무드 거리 85% + 원래 장르 비중 15%를 적용한 시제품 규칙이다. 기존 SPECTRA 추천 전체를 이식한 것은 아니며 계정·클라우드 데이터는 자동 연동하지 않는다. 현재 기본 취향은 가져온 라이브러리 기준으로, 자주 들은 횟수나 사용자의 감정 상태를 측정하지 않는다.

화면 캡처와 설명은 [운전자 시점 안내](docs/design/driver-view/README.md)를 참고한다.

`/design`에서 SPECTRA 디자인을 적용한 가로형 차량 화면과 4개 이용 장면을 검토할 수 있다. 32초 자동 시나리오 전환과 전체 보드(`/design/board`)를 제공한다. 시안은 샘플 데이터를 사용하며 실제 음성·음원·차량을 호출하지 않는다. 제출용 PNG·PDF와 검토 기준은 [화면 시안 안내](docs/design/README.md)에 있다.

## 퇴근 무드 시연

1. 내 취향 JSON을 가져온다. 실제 재생도 확인하려면 곡명과 일치하는 로컬 음원을 연결한다.
2. “편안하게”를 선택하고 조명 색상·밝기를 맞춘다. 조명은 화면의 실내 미리보기에만 적용된다.
3. “이거 퇴근 모드로 기억해” → 음악·조명 설정을 함께 저장한다.
4. 다른 무드로 바꾼 뒤 상단의 **시뮬레이션 목적지**를 집으로 선택한다.
5. “퇴근 모드로 바꿀까요?” 제안에서 **퇴근 모드 적용**을 선택한다. 이때 음악·조명이 함께 복원되며, 연결한 음원이 있으면 실제 재생한다.
6. “음악만 조금 더 신나게. 조명은 그대로” → 음악만 조정한다.
7. 아래 **시연 환경 설정**에서 조명 읽기 전용·미지원·오류를 선택한 뒤 무드를 바꿔, 음악은 변경되고 조명은 유지되는지 확인한다.
8. 목적지를 없음으로 바꾸고 위치 SDK 지원 환경 가정을 켠 뒤 **회사 영역 이탈 시뮬레이션**을 실행하면, 위치 이벤트에 의한 제안을 확인할 수 있다. 실제 기기 위치는 읽지 않는다.

목적지·위치 이벤트는 제안만 만든다. 사용자가 무드 적용을 선택하기 전에는 음악이나 조명이 바뀌지 않는다. 기본 집·회사는 샘플 좌표이며, 실제 사용자의 저장 장소가 아니다.

**로컬 음원 연결:** 파일명은 `곡명.mp3` 또는 `아티스트 - 곡명.mp3`처럼 취향 데이터와 일치해야 한다. 제목이 같은 곡이 여러 개면 아티스트를 포함한다. 파일은 서버로 업로드하지 않고 메모리의 Object URL로 재생하며, 취향 교체·새 음원 연결·화면 종료 시 해제한다. 파일 형식 지원은 브라우저에 따른다. 로컬 음원 연결만으로 자동 재생하지 않으며, 무드 적용이나 재생 버튼으로 시작한다. 스트리밍 서비스 연동·Android Media3 재생은 후속 범위다.

예시 문장 버튼 또는 텍스트 입력으로도 검증할 수 있다. 시제품의 문장 해석은 제한된 한국어 규칙에 기반하며 일반 대화를 이해하는 AI는 아니다. 지원하는 복합 문장은 위 시연 예시로 한정한다. 지원하지 않는 요청은 상태를 바꾸지 않고 다시 질문한다.

음성 입력은 브라우저의 SpeechRecognition 지원 및 마이크 권한에 따라 동작한다. 브라우저 구현에 따라 외부 음성 인식 서비스가 사용될 수 있다. Gleo 음성 입력을 사용하지 않는다. 로컬호스트 또는 HTTPS에서 사용하며, 지원하지 않는 브라우저는 텍스트 입력을 사용한다. 실제 사람 음성 인식 및 실제 차량 동작은 별도 검증 대상이다.

## 개인 취향 데이터

`내 취향 JSON 가져오기`에서 SPECTRA 형태의 `{ "tracks": [...] }` 또는 곡 배열을 읽는다. 가져온 곡은 이번 화면의 메모리에만 유지되며 서버로 전송하지 않는다. 음악·조명 설정과 최대 12개의 저장 무드만 localStorage에 저장한다. 이전 음악 전용 저장 데이터도 읽을 수 있으며 조명 기본값을 덧붙인다.

```json
{
  "tracks": [
    {
      "name": "내가 좋아하는 곡",
      "artists": "아티스트",
      "genres": ["indie", "acoustic"],
      "energy": 0.35,
      "valence": 0.6
    }
  ]
}
```

운전자·Pleos 데모는 `src/spectraDemoLibrary.js`, 이전 기능 시제품과 `/design`의 가상 샘플은 `src/demoLibrary.js`에 있다. `energy`, `valence`는 0~1 범위의 값이다. 없는 경우 일부 장르 태그에서 추정하고, 태그 근거도 없으면 중간값을 사용한다. 이 값은 음향 분석값이나 사용자의 감정 진단을 의미하지 않는다. 현재 추천은 가져온 곡 내부에서만 이루어지며 새로운 곡 탐색은 후속 개발 범위다. `익숙하게`는 중간 강도의 기본 무드이며 청취 빈도를 측정하지 않는다.

## 구조

```text
src/moodEngine.js             상태 전이, 문장 파서, 데이터 정규화, 추천 순위
src/App.jsx                   명령 실행, 브라우저 음성 입출력, 실제 로컬 음원 재생
src/JourneyPanels.jsx         이동 제안, 조명 미리보기, 시연 환경 설정
src/platform/                 조명 capability 분기, 경로·위치 맥락, Gleo 응답 계약
src/cockpit/                  운전자 시점, 차량 디스플레이, 취향 기반 대기열 어댑터
src/demoLibrary.js            가상 샘플 취향
integration/gleo/schema.json  공식 규격을 참고한 3개 기능의 스키마 초안
docs/DEVELOPMENT.md           SDK별 현재 구현 수준과 네이티브 개발 순서
docs/DESIGN_LANGUAGE.md       기존 SPECTRA 디자인 자산·토큰·별자리의 적용 기준
tests/                       핵심 사용 흐름과 데이터 경계 검증
```

기존 Taste Map과 라우팅·인증·환경변수를 공유하지 않는 별도 웹 앱이다. 운전자 데모는 원본의 순수 취향 분석 함수를 소스 의존성으로 사용한다. 현재 상위 Git 저장소에서 관리하며 새 원격 저장소는 만들지 않았다.
