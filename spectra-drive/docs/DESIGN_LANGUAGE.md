# SPECTRA → Drive 디자인 언어

기존 웹앱에서 만든 음악 취향의 시각적 정체성을 차량용 음성 경험으로 이어간다. 첫 반영일: 2026-10-22.

## 그대로 이어받은 자산과 규칙

| 기존 SPECTRA | Drive 적용 |
| --- | --- |
| `public/spectra-wordmark.svg`, `spectra-mark.svg` | 원본 SVG를 복사해 로고·파비콘으로 사용 |
| `src/index.css`의 Space Grotesk / Syne / Pretendard | 동일한 폰트 계열과 원본 HTML의 폰트 로딩 사용. 네트워크 불가 시 시스템 폰트 사용 |

## 취향과 무드의 관계

- 별 하나는 가져온 곡 하나다. 곡의 energy/valence를 좌표에 사용하며, 데이터가 없을 때의 장르 추정·중간값 처리는 기존 엔진을 따른다.
- 무드 전환은 추천된 곡의 밝기와 연결선을 바꾼다. 같은 곡의 좌표는 유지되어 개인 취향의 정체성이 이어진다.
- 48곡까지 표시한다. 큰 라이브러리에서는 추천 곡을 우선 포함하고 고정 해시로 선택한 곡으로 채운다. 전체 라이브러리가 항상 화면에 표시되는 것은 아니다.
- 지도 안의 선은 추천 곡을 시각적으로 잇는 표현이다. 실제 내비게이션 경로나 재생 진행률을 의미하지 않는다.
- 기본 무드와 저장 무드에는 작은 별자리 문양을 사용한다. 문양은 무드 유형을 표현하며 개인 청취 이력을 분석한 도형은 아니다.

## 차량용으로 조정한 부분

- 큰 음성 버튼과 짧은 응답을 주요 조작으로 둔다.
- 작은 화면에서는 현재 무드와 음성 조작을 먼저 보여준다.
- 별자리는 직접 터치할 필요가 없는 상태 표현으로 사용한다.
- 상시 회전·배경 비행은 사용하지 않고, 입력을 듣는 동안에만 음성 신호와 선택 링에 움직임을 준다. 동작 줄이기 설정도 따른다.
- 네이티브 구현에서는 정차 중 탐색·설정 화면과 주행 중 음성 화면을 구분하고 플랫폼 주행 제한 정책에 연결해야 한다. 현재 웹 시제품에는 차량 상태 제어가 구현되어 있지 않다.

## 음악과 실내 조명의 연결

동일한 무드 팔레트로 실내 조명 미리보기를 구현했다. 음악만 조정하면 조명은 그대로 유지하고, 저장 무드에는 음악과 요청 조명을 함께 담는다. 지원·읽기 전용·미지원·오류를 시연 설정에서 바꿔볼 수 있다. 실제 차량의 색상·밝기 범위는 capability 확인 후 매핑해야 한다. 현재 화면의 조명은 시뮬레이션이다.
