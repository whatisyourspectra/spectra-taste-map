# SPECTRA Drive · 차량 화면 시안 01

기존 SPECTRA의 워드마크, 남색 바탕, 하늘색·보라·핑크 팔레트, 별자리와 원형 음반 표현을 이어받은 차량용 화면 시안이다.

## 지금 높일 완성도

심사자가 한 번의 시연으로 **내 취향 → 이동 상황에 맞는 제안 → 음성 요청 → 음악·조명 전환 → 필요한 부분만 조정**을 이해할 수 있도록 화면과 전환을 다듬는다.

1. **차량 화면 시안:** 가로형 화면에서 현재 무드, 음악, 조명, 이동 맥락을 한눈에 이해할 수 있게 정리한다.
2. **동작의 일관성:** 같은 요청에는 같은 결과가 나오고, “조명은 그대로”라고 하면 조명 색상·밝기가 유지되는지 검증한다. 기존 기능 시제품의 실제 로컬 음원 재생도 함께 활용한다.
3. **짧은 시연 영상:** 네 장면을 30~45초에 담고 요청과 결과를 자막으로 보여준다. UI 시안과 실제 구현 범위는 구분해서 표시한다.
4. **Pleos 실행 증거:** SDK 접근 조건을 확인한 뒤 Kotlin 앱, 실제 Gleo 호출, 재생·조명 제어가 이어지는 APK 구동을 확보한다. 최종 제출 시점에는 실제 동작 범위에 맞춰 자료를 갱신한다.

## 네 장면

| 장면 | 보여줄 가치 | 파일 |
| --- | --- | --- |
| 01 정차 · 나의 취향 | 출발 전 음악과 조명을 개인 무드로 준비 | screens/01-ready.png |
| 02 이동 · 퇴근 무드 제안 | 집으로 향하는 맥락을 이용한 제안, 사용자의 적용 선택 | screens/02-suggestion.png |
| 03 음성 · 음악과 조명 전환 | 한 번의 요청으로 음악 설정과 조명을 함께 복원 | screens/03-applied.png |
| 04 조정 · 음악만 조금 더 | 음악 활기 36% → 48%, 조명 하늘빛 42% 유지 | screens/04-refined.png |

장면의 음악 활기는 시안용 무드 설정값이다. 실제 감정 상태나 측정한 청취 데이터가 아니다. 샘플 곡과 경로를 사용하며, 시안에서는 음원·마이크·Gleo·실제 차량을 호출하지 않는다. 조명 수치는 실제 차량 제어 결과가 아니다.

## 확인 방법

- `npm run dev` 실행 후 `/design`에서 네 장면을 넘겨본다.
- 퇴근 무드 제안 화면의 적용 버튼으로 다음 장면을 확인할 수 있다.
- 하단 음성 요청 예시를 누르면 다음 요청·결과 장면을 확인한다. 실제 음성 인식은 수행하지 않는다.
- `32초 시나리오 자동 재생`은 네 장면을 각 8초씩 반복한다. 녹화 파일이나 실제 Gleo 시연 영상은 아니다.
- `/design/board`에서 네 장면 보드를 본다.
- 기존 `/` 기능 시제품에서 실제 로컬 음원 재생, 조명 권한 분기, 경로 제안 승인을 검증할 수 있다.

## 제출용 산출물

- `screens/`: 2000 × 1126 PNG 4장. 화면 안에 시안·샘플·미연결 표시를 유지했다.
- `SPECTRA_Drive_Design_Board.png`: 네 장면을 묶은 시안 보드.
- `SPECTRA_Drive_Design_Board.pdf`: 한 장짜리 검토·첨부용 PDF.

공모전 02 소개 자료의 7번 참고자료에 이 화면 4장 또는 보드 PDF를 첨부할 수 있다. 실제 동작 영상은 기능 시제품에서 로컬 음원을 연결한 뒤 별도로 촬영하고, 시안과 실제 구현 화면을 구분해서 설명한다.

현재 자료는 화면 디자인 및 인터랙션 시안이다. 향후 APK 구현 시 플랫폼 주행 제한 정책과 실제 디스플레이에서의 가독성·조작성을 별도로 검증해야 한다.

## 다시 내보내기

Playwright와 Chromium을 사용할 수 있는 환경에서 개발 서버를 켠 다음 실행한다.

```sh
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs CHROMIUM_EXECUTABLE=/path/to/chromium node scripts/export-design.mjs
```

내보내기 과정에서 화면 범위, 로고 로드, 장면 전환, 음악만 조정할 때 조명 유지, 자동 시나리오 재생을 확인한다. 브라우저가 샌드박스에서 차단되면 실행 권한이 필요할 수 있다.
