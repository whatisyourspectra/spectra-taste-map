# SPECTRA Drive / Hangang Study 03

핵심 문제: 차 안에서는 폰처럼 음악 리스트를 손으로 쉽게 편집할 수 없다. 무드는 ‘지금 듣고 싶은 음악’을 말로 표현하는 수단이며, 선택 근거는 기존 SPECTRA 취향이다.

## 보기

`npm run dev` 후 http://127.0.0.1:5190/drive 에 접속한다. PC 가로 화면에서 한강 노을이 보이는 운전석을 보고, ‘화면 확대’로 앱의 변화를 확인한다. ‘몰입 보기’는 전체 화면으로 전환하며, 화면 비율에 맞춰 장면 전체를 유지한다. ‘28초 자동 시연’은 세 가지 예시 요청을 순서대로 실행한다. 화면 녹화 파일을 생성하는 기능은 아니다.

## 캡처

최신 캡처는 `hangang-v2/`에 있으며 기존 벡터 캡처는 현재 폴더에 보존했다.

- `01-driver-ready.png`: 운전석 전체, 기본 취향과 현재 곡
- `02-driver-calm.png`: 편안한 무드로 다음 재생곡 변경
- `03-display-calm.png`: 인포테인먼트 확대, 차분한 대기열
- `04-display-uplift.png`: 활기 조정 뒤 대기열 변경, 현재 곡 유지
- `05-mobile.png`: 모바일에서의 조작 패널

최신 데모와 `hangang-v2/` 캡처는 기존 SPECTRA의 곡 메타데이터 18곡과 로컬 앨범 커버 17종을 사용한다. 현재 곡의 기본값은 Tame Impala의 The Less I Know the Better다. 실제 개인 계정이나 음원은 포함하지 않으며 무드 수치는 기존 데모의 예시값이다. 현재 폴더의 이전 벡터 캡처는 SPECTRA Sessions 가상 메타데이터를 사용했다. 기본 풍경은 정적인 AI 생성 이미지이며 실제 주행 영상이나 3D 차량 모델은 아니다. 두 디스플레이, 조명 피드백, 공조 표시, 음성 버튼은 코드로 별도 합성한다. 실내 소재의 질감과 노을 반사광은 생성 이미지에 포함된다.

## 동작과 표현의 경계

- 실제 로직: 기존 SPECTRA `buildTasteState`의 장르 분포·평균값, 세션 무드에 따른 재정렬, 현재 곡 유지, 별자리 위치 유지, 데이터 가져오기, 연결한 로컬 음원 재생.
- 원본과의 관계: 별자리 토폴로지·장르 색·브랜드 자산을 재사용하고 순수 취향 분석 함수를 직접 호출한다. 원본 추천 전체의 이식이나 클라우드 계정 연동은 아니다.
- 모의 동작: 속도·기어·배터리·도착시간·도로·차량 형상, 예시 음성 및 자동 시연의 음성 입력. 실제 주행 데이터나 Gleo 응답이 아니다.
- 음성: 브라우저 SpeechRecognition 지원과 마이크 권한이 필요하다. 브라우저에 따라 외부 음성 인식 서비스를 사용할 수 있다. 사람의 실제 발화는 별도 검증 대상이다.
- 샘플 곡에는 오디오가 없다. 실제 재생은 개인 JSON과 곡명이 일치하는 로컬 파일을 연결한 경우에만 가능하다.
- 현재 모델은 장르 태그와 제공된 수치를 사용한다. 감정 인식, 음원 분석, 청취 빈도 학습을 구현한 것은 아니다.

## 차량 참고

[현대자동차 IONIQ 6 공식 실내 안내](https://www.hyundai.com/id/en/find-a-car/ioniq-6/interior)의 통합 듀얼 12.3인치 디스플레이, 스티어링 휠, 대시보드 배치를 참고했다. 기존 벡터 구도를 유지하면서 내장 imagegen으로 실내 소재와 한강 노을 풍경을 생성했다. 제조사 사진 자체는 웹에 게시하지 않았으며, 제조사 UI의 정밀 복제나 실제 차량의 디지털 트윈은 아니다. 이 차종에서 Pleos 앱이 실제 동작한다는 의미도 아니다.

생성 자산은 `public/cockpit/ioniq6-hangang-sunset-v2.png`에 저장했다. 도구와 최종 프롬프트는 [생성 기록](HANGANG_IMAGE_PROMPT.md)에 있다. 실제 디스플레이는 이미지 위에 HTML로 합성하고, 클러스터는 스티어링 휠의 외곽에 맞춘 CSS 마스크를 적용했다.

## 검증

`npm test`, `npm run build`. 브라우저 검증은 `node tests/driverBrowser.mjs`로 실행하며 환경에 따라 `PLAYWRIGHT_MODULE`, `CHROMIUM_EXECUTABLE`을 지정한다. 브라우저 검증은 배경 파일 로딩, 예시 요청, SpeechRecognition 이벤트 어댑터, 기본 취향 복원, 별자리 좌표 유지, 자동 시연 중단, 전체 화면 진입·종료 및 장면 잘림, 개인 파일 가져오기, 실제 WAV 재생 중 무드 변경, 320~1600px 페이지 가로 넘침을 확인한다. 실제 마이크·Gleo·차량은 검증하지 않는다.
