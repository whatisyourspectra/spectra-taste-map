# 02 앱 프로젝트 소개 / 심사 자료

작성 초안 · 2026.10.22 기준

접수번호: 운영사 기재

앱명 / 프로젝트명: SPECTRA Drive (스펙트라 드라이브)

## 1. 앱 한 줄 소개

나의 음악 취향과 이동 상황을 바탕으로, 음성 한마디로 음악과 지원 차량의 실내 조명을 함께 조정하는 Pleos Connect용 개인화 무드 앱입니다.

## 2. 기획 배경

주목한 고객은 주 3회 이상 자가용으로 출퇴근하며 자신이 좋아하는 음악 목록을 보유한 운전자입니다. 반복되는 이동 시간을 원하는 분위기로 바꾸고 싶어도, 운전 중 곡과 플레이리스트를 검색하거나 음악과 차량 조명을 각각 설정하는 과정에는 화면을 확인하고 조작하는 부담이 따릅니다.

사용자는 특정 곡명이나 장르보다 “오늘은 편안하게 가고 싶다”, “지금보다 조금만 신나게 듣고 싶다”처럼 원하는 분위기를 표현할 수 있습니다. SPECTRA Drive는 이러한 표현을 개인의 음악 취향과 연결하고, 지원되는 차량 기능까지 함께 조정하는 경험을 제안합니다.

기존 SPECTRA 웹앱의 취향 분석과 별자리 시각화를 기반으로, 차량에서는 음성을 중심으로 간단하게 무드를 바꾸는 이용 흐름을 설계했습니다. 초기에는 반복 이용이 가능한 출퇴근 상황에 집중해 실제 사용성을 검증할 계획입니다.

## 3. 앱 주요 기능 및 차량 특화 요소

① 내 취향 기반 무드 선택: 사용자가 가져온 좋아요 곡·플레이리스트와 장르·무드 정보를 바탕으로, 원하는 활기와 밝기에 가까운 곡을 선택합니다. 같은 “편안하게”라는 요청도 각자의 음악 목록에 맞춰 다르게 구성합니다.

② 음성으로 세밀하게 조정: “조금 더 신나게”, “음악만 바꾸고 조명은 그대로”와 같은 요청으로 음악과 조명을 함께 또는 독립적으로 조정합니다. 무드의 이름을 말해 현재 음악·조명 설정을 저장하고 다시 불러올 수 있습니다.

③ 음악과 차내 조명의 연결: 지원 차량에서는 음악 무드에 맞춰 실내 앰비언트 조명의 색상·밝기를 함께 요청합니다. 차량별 지원 범위와 접근 권한을 확인하고, 조명 기능을 사용할 수 없는 환경에서도 개인화 음악 기능을 유지하도록 설계합니다.

④ 이동 맥락에 따른 제안: 내비게이션 목적지가 사용자가 저장한 집 위치와 일치하거나, 지원 환경에서 회사 영역 이탈이 감지되면 저장한 퇴근 무드를 제안합니다. 사용자가 적용을 선택하기 전에는 음악이나 조명을 변경하지 않습니다.

⑤ SPECTRA의 일관된 시각 경험: 개인의 곡을 별과 연결선으로 보여주는 취향 지도를 활용하고, 현재 무드에 해당하는 곡을 강조합니다. 정차 중에는 취향과 저장 무드를 살펴보고, 주행 중에는 짧은 음성 요청과 응답을 중심으로 이용하도록 개발합니다.

차량에서의 핵심 가치는 개인 음악 데이터, 음성 인터페이스, 경로·차량 기능을 하나의 이용 흐름으로 연결한다는 점입니다. 음악과 실내 환경을 함께 다루면서 반복되는 이동 상황에 저장한 설정을 다시 활용할 수 있습니다.

## 4. 주요 사용 시나리오

대표 시나리오는 업무를 마친 운전자의 퇴근길입니다. 아래는 최종 구현을 목표로 한 이용 흐름입니다.

1) 출발 전 정차 상태에서 자신의 음악 취향을 불러옵니다. 편안한 음악 성향과 조명 색상·밝기를 맞춘 뒤 “이거 퇴근 모드로 기억해”라고 말해 함께 저장합니다.

2) 이후 집으로 향하는 내비게이션 경로가 설정되면, 앱이 목적지와 사용자가 저장한 집 좌표를 비교해 “저장한 퇴근 모드로 바꿀까요?”라고 제안합니다. 위치 기능이 지원되는 경우에는 회사 영역 이탈도 제안의 계기로 활용합니다.

3) 사용자가 “스펙트라, 퇴근 모드로 바꿔줘”라고 요청하면, 앱이 개인 취향에 맞는 음악 설정을 복원하고 지원되는 조명을 함께 적용합니다. 재생 가능한 음원이 연결되어 있으면 음악을 재생합니다.

4) 이동 중 “음악만 조금 더 신나게. 조명은 그대로”라고 말하면, 조명을 유지한 채 음악의 활기만 조정합니다. 화면에서 여러 설정을 찾아갈 필요 없이 원하는 부분을 말로 지정합니다.

5) 앱은 실제 처리 결과를 짧게 안내합니다. 조명을 적용하지 못한 경우에는 음악과 조명의 결과를 구분해 알려주며, 새로운 분위기를 다시 저장해 다음 이동에 활용할 수 있습니다.

## 5. 개발 계획

현재 개발 현황: 웹 시제품에서 음악·조명 설정의 저장과 복원, 제한된 문장 기반 음성·텍스트 조정, 개인 취향 JSON 가져오기, 연결한 로컬 오디오 파일의 실제 재생을 구현했습니다. 조명 지원·권한·오류 분기와 경로·위치에 따른 제안은 시뮬레이션으로 검증했습니다. 실제 Gleo AI·Pleos SDK 연동, Kotlin 앱 및 APK는 아직 구현하지 않았습니다.

개발 환경: Android API 28 이상, Gradle 8.0 이상을 기준으로 Kotlin 기반 Pleos Connect 앱을 개발합니다. 기존 시제품의 무드 상태 모델과 음악·조명 분리 로직을 네이티브 환경으로 옮기고, Pleos Connect Emulator에서 구동과 오류 대응을 검증합니다.

• Gleo Interface: 무드 전환, 음악·조명 개별 조정, 무드 저장의 3개 기능을 App Schema로 정의하고 Intent 수신과 결과 callback을 구현합니다. 인수 누락과 부분 실패를 구분해 응답합니다.

• SpeechToText / TextToSpeech SDK: 앱 내부 음성 입력과 짧은 처리 결과 안내에 활용합니다. Gleo를 통해 들어온 요청은 Gleo의 응답 경로를 사용해 앱 음성과 중복되지 않도록 합니다.

• Vehicle SDK / AAOS Car API: 조명의 capability와 승인된 접근 권한, 지원 색상·밝기 범위를 확인한 뒤 요청을 적용합니다. 표준 차량 상태는 지원되는 AAOS API를 활용하고, 주행 제한 정책에 따라 탐색·가져오기 등 복잡한 조작을 제한합니다.

• NaviHelper SDK: 목적지와 경로 상태를 받아 사용자가 저장한 장소 좌표와 비교하고, 적절한 이동 무드를 제안합니다. 경로가 바뀌거나 취소되면 이전 제안도 갱신합니다.

• FusedLocation SDK: isSupported()와 접근 조건을 확인한 환경에서 위치·영역 진입/이탈 이벤트를 활용합니다. 미지원 또는 위치를 확인할 수 없는 환경에서는 해당 기능을 제외하고 음성·경로 기반 전환을 유지합니다.

• 음악 재생: 초기에는 사용자가 제공한 재생 가능한 로컬 음원을 기준으로 개인화 흐름을 검증하고, Android Media3 / MediaSession과 오디오 포커스를 적용합니다. 외부 음원 서비스는 실제 접근 권한과 재생 지원 범위를 확인한 뒤 연동 범위를 결정합니다.

개발은 ① Kotlin 앱과 Gleo 호출, ② 개인 취향 기반 음악 재생, ③ 지원 차량의 조명 연동, ④ 내비게이션 맥락, ⑤ 지원 환경의 위치 기반 제안 순으로 진행합니다. 2차 PT 전까지 핵심 이용 흐름이 동작하는 APK 완성을 목표로 하며, SDK 접근 조건과 지원 환경을 우선 확인해 구현 범위를 확정합니다.

## 6. 기대효과 및 발전 가능성

사용자에게는 원하는 분위기를 만들기 위한 음악 탐색과 개별 설정의 부담을 줄이고, 익숙한 취향을 유지하면서 이동 상황에 맞춰 음악과 조명을 조정하는 가치를 제공합니다. 실제 효과는 기존의 곡 선택·조명 설정 방식과 비교해 화면 조작 횟수, 음성 명령 성공률, 무드 적용 완료율을 측정하며 검증할 계획입니다.

초기 타깃은 자신만의 음악 목록을 보유하고 주 3회 이상 자가용으로 출퇴근하는 운전자입니다. 기존 SPECTRA 웹앱의 안내와 음악·자동차 커뮤니티를 통해 자발적 테스트 참여자를 모집하고, 최초 취향 가져오기와 무드 저장·재사용 경험의 개선에 집중합니다.

초기 지표 목표: 공개 베타 시작 후 3개월 동안 누적 참여자 200명, MAU 100명, D30 유지율 30%를 검증 목표로 설정합니다. MAU는 해당 월에 한 번 이상 무드를 적용한 고유 사용자 수, D30 유지율은 첫 무드 적용 후 30일째 다시 무드를 사용한 비율로 정의합니다. 이는 현재 실적이나 검증된 수요 예측이 아닌 초기 목표 가정이며, 지원 차량 범위와 파일럿 결과에 따라 조정합니다.

서비스는 출퇴근에서 출발해 주말 드라이브, 충전 대기, 휴식 등으로 확대할 수 있습니다. 이후 동승자와 취향을 조합하는 기능, 이동별 저장 무드, 사용자가 명시적으로 선택·수정한 기록에 따른 개인화를 검토합니다. 반복 이용 가치가 확인되면 고급 개인화와 무드 관리 기능의 유료화 가능성도 검증할 계획입니다. Pleos App Market 배포는 별도 검증·심사를 거치는 것을 전제로 합니다.

## 8. 숏폼 링크(선택 · 가산점 없음)

현재 게시한 숏폼 링크는 없습니다. 참여할 경우 “퇴근 모드 한마디로 내 음악과 차 안의 분위기가 바뀌는 순간”을 주제로 세로 영상을 제작하고, 게시 후 링크를 기재할 예정입니다. 미참여 시에는 해당 없음으로 기재합니다.
